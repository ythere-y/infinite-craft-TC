# Issue #16 手机端主游戏布局与触控适配设计

## 背景与目标

主游戏当前以桌面端固定顶栏和右侧元素栏为主。手机竖屏下，顶栏入口容易拥挤，固定元素栏会持续压缩画布，触控拖拽还可能与页面滚动、浏览器手势和双击复制冲突。

本次改动以常见手机竖屏为主要场景，保持画布为核心操作区域，同时保证搜索、元素拖拽、合成、图鉴、KPI、清空、首发榜、公式广场和帮助入口可用。桌面端布局与鼠标双击复制必须保持兼容。

## 范围

### 包含

- 主游戏页面的手机竖屏响应式布局。
- 右侧元素抽屉及其打开、关闭和拖入后自动收起行为。
- 手机端精简顶栏和“更多”菜单。
- 触控拖拽、滚动、软键盘和安全区适配。
- 手机端禁用双击或连续轻触复制。
- 相关前端自动测试和桌面端回归验证。
- 浅色主题与 URA 主题下的新组件样式。

### 不包含

- 后端接口、数据库或 Makers KV 变更。
- 社区广场、首发榜等独立页面的整体移动端重构。
- 新前端框架、路由系统或账号系统。
- 平板横屏或桌面端布局重设计。

## 布局与组件

### 桌面端

断点以上继续使用现有布局：完整顶栏、固定右侧元素栏和主画布。手机专用的“元素”与“更多”入口隐藏。

### 手机端

- 页面使用动态视口高度，主画布占据顶栏以下空间，根页面不产生非预期横向滚动。
- 现有元素侧栏复用为右侧抽屉。抽屉宽度使用视口比例并设置最大宽度，关闭时完全移出视口。
- 抽屉保留搜索框、已发现数量和元素列表。列表内部允许纵向滚动。
- 抽屉打开时显示与现有主题一致的轻量遮罩。
- 顶栏只保留紧凑的品牌/昵称区域、“元素”按钮和“更多”按钮。
- “更多”菜单复用现有按钮和链接能力，提供图鉴、KPI、清空画布、首发榜、公式广场和帮助入口。
- 点击遮罩、按 Escape、选择“更多”菜单项或成功把元素拖入画布后，关闭对应浮层。
- KPI、图鉴、昵称确认等已有面板在小屏幕下受视口宽高约束，并使用内部滚动，避免被软键盘或安全区遮挡。

新组件沿用现有按钮、圆角、边框、阴影和主题颜色。URA 模式为抽屉、遮罩、菜单和移动端按钮提供对应暗色规则，不引入独立视觉体系。

## 状态与事件流

新增轻量的移动界面控制状态，不改变游戏数据：

- `sidebarOpen`：控制元素抽屉和遮罩。
- `mobileMenuOpen`：控制“更多”菜单。
- `dragging`：沿用现有拖拽状态，并在活动期间抑制冲突手势。

界面入口通过按钮设置状态；遮罩、Escape 和菜单操作负责复位状态。媒体查询跨越手机断点时，所有临时浮层状态会被清理，避免旋转屏幕或调整窗口后遗留遮挡。

拖拽流程继续使用现有 Pointer Events：

1. 元素收到主指针 `pointerdown` 后创建 ghost 并捕获指针。
2. 活动拖拽期间更新 ghost 和画布目标，不让页面滚动抢走手势。
3. `pointerup` 在画布内执行新增、移动或合成。
4. 如果元素来自侧栏且成功落入画布，关闭右侧抽屉。
5. 如果拖拽取消或落在画布外，清理 ghost 和拖拽样式，但保持抽屉打开以便重试。
6. `pointercancel` 与普通释放走同一套幂等清理逻辑。

## 触控与双击规则

- 可拖拽元素使用合适的 `touch-action`，活动拖拽期间锁定冲突滚动。
- 抽屉元素列表和搜索框仍支持正常纵向滚动及文本输入。
- 双击复制仅接受鼠标指针。触摸、触控笔及触摸产生的合成 `dblclick` 不调用复制处理器。
- 手机帮助文案不展示双击复制提示；桌面帮助文案继续说明鼠标双击能力。
- 使用动态视口单位和安全区 inset，确保软键盘弹出后搜索框可见、列表可滚动，底部内容不被系统区域遮挡。

## 可访问性与错误处理

- 抽屉和菜单按钮使用 `aria-expanded`、`aria-controls` 和明确的 `aria-label`。
- 抽屉与更多菜单的显示状态同步更新无障碍属性。
- Escape 可关闭当前浮层；触发按钮保留可恢复的键盘焦点。
- 可点击入口保持足够的触控尺寸，并使用真实 `button` 或 `a` 元素。
- 浮层关闭和拖拽清理必须幂等，重复事件不会遗留遮罩、滚动锁或 ghost。
- API 错误继续使用现有合成反馈路径，本次不改变错误文案或重试策略。

## 测试与验收

### 自动测试

- 验证主页面包含移动端元素按钮、更多菜单、抽屉遮罩和必要的 ARIA 关联。
- 验证 CSS 包含手机断点、右侧抽屉、安全区、动态视口和防横向溢出规则。
- 验证移动界面控制能打开/关闭抽屉与菜单，并在成功拖入后关闭抽屉。
- 验证 double-tap 处理拒绝非鼠标指针，同时保留鼠标 `dblclick`。
- 运行 `npm test`。
- 运行 `python3 -m pytest tests --ignore=tests/test_combine_feedback.py -q`。
- 运行 `npm run build`。

### 手动验收

- 在常见手机竖屏宽度（至少 320、375、390 和 430 CSS px）检查无横向滚动、顶栏溢出或界面遮挡。
- 打开右侧抽屉、搜索元素、纵向滚动列表，并拖入画布完成一次合成。
- 验证成功拖入后抽屉自动关闭；取消拖拽时抽屉保持打开。
- 连续轻触侧栏、图鉴和画布元素，确认不会复制。
- 用桌面鼠标验证拖拽、合成和双击复制无回归。
- 验证图鉴、KPI、清空、首发榜、公式广场和帮助入口可用。
- 在浅色和 URA 主题下检查抽屉、遮罩、菜单、按钮和面板视觉一致。
- 聚焦搜索框并弹出软键盘，确认输入框和列表仍可操作。
- 在带安全区的设备模拟下确认顶栏和底部内容不被遮挡。

## 完成标准

Issue #16 的所有验收项通过，自动测试和构建成功，桌面端主要操作无回归；PR 合并并自动部署后，在线上手机视口和桌面视口各完成一次验收。
