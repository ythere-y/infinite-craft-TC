# 配方点评卡片内嵌设计

## 目标

配方弹窗中的点评必须明显归属于对应的合成公式。点评不再显示在公式卡片背景之外，而是与公式行共享同一背景、边框、圆角和悬停状态。

## 布局

- `.recipe-entry` 成为完整配方卡片，承载背景、边框、圆角与 hover。
- `.recipe-row` 继续显示两个元素、加号和来源标签，但自身不再绘制独立卡片背景。
- 有非空点评时，`.recipe-entry` 增加 `has-comment` 状态。
- `.recipe-comment` 位于公式行正下方，使用 12px 次要文字，和公式行保持约 3–4px 的紧凑垂直间距。
- 没有点评的配方不渲染点评节点，也不增加额外高度，保持紧凑单行。

## 行为与兼容

- 不改变 API、点评选择规则或文本安全策略。
- AI 配方优先显示其归档 comment，旧数据继续使用已存在的社区公式回退。
- 长点评允许在卡片内部自然换行，不溢出卡片。
- 桌面与窄屏使用同一结构，卡片内容必须完整包含公式和点评。

## 验证

- 浏览器布局测试确认公式与点评位于同一非透明背景容器内。
- 有点评时，点评紧贴公式且被卡片边界完整包裹。
- 无点评时不出现空白点评区域。
- 运行前端测试、完整 Python 测试、构建，并通过服务器 IP 验收真实页面。
