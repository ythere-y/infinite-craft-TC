# 配方库关闭按钮与公式密度微调设计

日期：2026-07-31

## 目标

修正配方库关闭按钮中通用动作图标容器造成的尺寸和居中显示问题；同时缩小公式元素与间隔，并单独强化加号和箭头，使公式更紧凑但运算关系更清晰。

## 已确认方案

采用方案 A：保留现有图标系统和关闭按钮的语义化 HTML，仅在配方库作用域内覆盖内部 `.action-icon` 与图片的尺寸、布局和夜间滤镜。不得影响其他使用动作图标的按钮。

公式行进行以下调整：

- 缩小普通、紧凑和超紧凑三档中的元素图标、名称字号、Chip 内边距、行间距与行内边距。
- 加号不再继承普通元素 Chip 的横向内边距，避免占用多余空间。
- 加号和箭头使用更高对比度、略大的字号与更明显的字重。
- 测量压缩档中，运算符保持比元素文字更大的相对尺寸；实际宽度仍由现有 `scrollWidth/clientWidth` 测量循环校正。
- 所有公式继续保持单行、完整显示，不使用省略号或换行。
- 日间和夜间模式分别提供适当的运算符颜色。

## 关闭按钮

- 保留 30×30 像素按钮点击区域、右上角位置、标题、ARIA 标签、键盘焦点和关闭行为。
- 内部动作图标容器占满按钮但不继承全局 25 像素最小宽度。
- X 图片使用明确的小尺寸和块级布局，确保几何居中。
- 夜间模式继续对实际 SVG 图片应用可见性滤镜。

## 验证

扩展现有真实生产页面浏览器测试，先建立失败断言，再实施 CSS/测量变量修改。测试覆盖：

- 关闭按钮内部容器和 X 图片的实际尺寸与居中误差。
- 普通公式的元素图标、Chip 间距和行间距确实小于旧值。
- 加号和箭头相对元素文字更醒目且颜色有足够区分。
- 长公式在桌面和移动端保持单行并不溢出。
- 夜间模式、键盘焦点、关闭行为以及公式元素双击交互不回归。
