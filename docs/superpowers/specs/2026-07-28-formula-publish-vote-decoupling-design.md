# 公式公开与投票解耦设计

## 目标

保留合成后的“公开公式”动作，但去掉成功后的二阶段跳转入口。公开只控制公式是否进入公开展示列表；投票作为社区反馈信号，不依赖公式是否已公开。

## 交互

- 合成成功且响应包含 `formula_id` 时，反馈气泡内显示按钮：`公开这个公式`。
- 点击成功后停留在当前画布。
- 成功状态只显示：`✅ 已公开`。
- 不显示“查看广场”链接，也不显示“社区现在可以投票”。
- 失败时恢复按钮可用，并显示服务端错误或“公开失败，请重试”。
- 气泡仍沿用现有 8 秒生命周期，公开成功或失败不延长展示时间。

## 后端语义

- `publish` 仍要求服务端记录过该匿名玩家实际复现过该公式。
- `vote` 允许对 `status=active` 的公式投票，不再要求 `visibility=public`。
- 公开列表仍只返回 `visibility=public` 的公式。
- 对未公开公式投票时，响应只返回投票状态与计数，不返回输入、结果、点评等公式内容。

## 不包含

- 不自动跳转首发榜或公式广场。
- 不公开未公开公式的详情。
- 不改变公开列表排序、治理队列阈值或管理员治理动作。
