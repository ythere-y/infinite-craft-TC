# 合成反馈与公式公开气泡合并设计

## 目标

合成成功后只展示一个固定在右下角的反馈气泡。现有合成结果、发现状态、
难度、得分和模型点评继续显示，并将“公开到公式广场”操作融合到同一个气泡
中。统一气泡展示 8 秒。

## 现状

一次成功合成当前会同时触发两个独立反馈：

- `#first-toast` 位于右下角，展示发现状态、结果、难度、得分和模型点评，
  4.2 秒后隐藏；
- `.formula-publish` 位于页面底部中央，展示“公开到公式广场”按钮，
  12 秒后删除。

两个组件由同一次 `/api/combine` 响应触发，但使用不同容器、位置和计时器，
造成重复气泡和割裂的操作体验。

## 采用方案

复用现有 `#first-toast` 作为唯一容器，在点评下方增加独立的公式公开操作区。
不新增另一套反馈组件，也不通过 CSS 叠放两个独立容器。

采用这一方案的原因：

- 保留现有三档发现状态、颜色与合成特效；
- 公式发布请求仍由 `frontend/app.js` 负责，视觉模块不承担业务 API 调用；
- 只调整与本需求直接相关的前端结构和样式；
- 下一次合成能够原子地替换整个反馈内容并重置生命周期。

## 组件职责

### `frontend/combine-feedback.js`

继续负责用 `textContent` 安全渲染合成结果和点评。现有渲染函数保持对模型
输出的安全边界，不使用 `innerHTML`。

### `frontend/effects.js`

继续负责发现等级对应的视觉效果和 `#first-toast` 的显示状态。Toast 的自动
隐藏时间从 4.2 秒统一改为 8 秒。每次合成先取消旧计时器，再启动新的 8 秒
计时器。

### `frontend/app.js`

`showPublishAction()` 不再创建或删除 `.formula-publish` 浮层，而是在
`#first-toast` 中追加 `.first-toast-actions` 操作区：

- 输入为 `formulaId` 和合成结果名；
- 显示“公开到公式广场”按钮；
- 点击后禁用按钮并发起现有发布请求；
- 成功后仅替换当前操作区为“已公开，社区现在可以投票”和“查看广场”链接；
- 失败后恢复按钮，并显示服务端错误或统一失败文案。

合成响应没有 `formula_id` 时不创建操作区。

### `frontend/style.css`

删除独立 `.formula-publish` 气泡样式，新增统一气泡内的操作区样式。
`#first-toast` 在存在操作按钮或链接时允许操作区接收指针事件；按钮和链接
沿用公式广场的绿色操作色，但与三档 Toast 背景保持足够对比。

## 展示结构

统一气泡从上到下展示：

1. 发现状态、难度和得分；
2. Emoji 与合成结果名称；
3. 模型点评；
4. “公开到公式广场”操作区，仅在响应包含 `formula_id` 时出现。

桌面端保留当前右下角位置。宽度继续受视口限制。移动端保持左右各 12px，
操作按钮至少 44px 高，文本允许换行且不得与其他内容重叠。

## 生命周期与竞态

- 每次成功合成展示气泡 8 秒；
- 下一次合成会替换当前气泡全部内容、清除旧按钮并重新计时；
- 发布请求完成时只更新该次请求捕获的操作区节点；
- 如果下一次合成已经替换气泡，旧操作区已脱离文档，旧请求完成后不得修改
  新气泡；
- 发布成功或失败不会额外延长 8 秒生命周期；
- 8 秒后仅隐藏气泡，下一次渲染会清理旧内容。

## 错误处理

- 请求发送后按钮立即禁用，防止重复提交；
- 非成功响应恢复按钮可用状态；
- 优先显示响应中的 `detail`，缺失时显示“公开失败，请重试”；
- 无法解析错误响应时使用统一失败文案；
- 合成请求本身的失败提示保持现状，不显示公式公开操作。

## 测试

自动化测试覆盖：

- 合成反馈使用 8000 毫秒自动隐藏；
- 包含 `formula_id` 时操作按钮位于 `#first-toast` 内；
- 页面不再创建 `.formula-publish` 独立气泡；
- 不含 `formula_id` 时不显示公开操作；
- 发布成功只替换操作区，并生成正确的广场链接；
- 发布失败恢复按钮并显示错误；
- 旧发布请求完成时不会覆盖下一次合成产生的新气泡；
- 模型和服务端文本继续通过 `textContent` 渲染；
- 移动端操作按钮满足最小点击高度，统一气泡不会横向溢出。

## 不包含

- 修改公式公开资格、投票或治理规则；
- 修改发布 API、匿名身份或服务端存储；
- 增加手动关闭按钮；
- 发布成功或失败后延长气泡展示时间；
- 改造公式广场页面。
