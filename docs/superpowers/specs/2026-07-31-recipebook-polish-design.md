# 配方库关闭按钮与长公式适配设计

## 目标

修复配方库左上角红色关闭按钮不自然的问题，并提高超长公式在单行列表中的可读
性。普通配方保持当前视觉密度，只有实际放不下的行才缩小。

## 抽屉与关闭按钮

- 桌面端抽屉宽度从 420px 增加到 480px。
- 实际宽度使用 `min(480px, 100vw)`，小屏幕不产生横向页面溢出。
- 关闭按钮移到标题栏右上角。
- 按钮为 30×30px 的浅灰圆角方形，使用现有图标系统渲染细线关闭图标。
- 删除红色 Mac 交通灯外观及其仅用于布局的容器。
- 悬停时背景稍加深；键盘聚焦时显示清晰轮廓。
- 保留现有 `title`、`aria-label` 和点击关闭行为。
- 夜间模式使用同结构的深色中性按钮，不恢复红色交通灯。

## 配方行自适应

配方继续保持单行，顺序仍为：

```text
元素 A + 元素 B → 结果 +分数
```

每行插入列表后，根据真实 `scrollWidth` 和 `clientWidth` 判断是否溢出：

1. 正常行保持现有尺寸。
2. 溢出时增加 `recipe-row-dense`。
3. 重新测量后仍溢出时增加 `recipe-row-ultra-dense`。

紧凑等级同步缩小：

- 元素图标；
- 元素名称字号；
- chip 内边距和圆角；
- 行内间距；
- 加号与箭头；
- 分数标签。

不通过字符数猜测长度，不截断名称，也不改变拖拽、双击和搜索高亮行为。480px
抽屉配合两档缩放应覆盖正常数据；测试使用长中文元素名验证超紧凑档仍保持单行。

## 渲染与重新测量

- `renderRecipebook()` 完成一行 DOM 插入后立即执行密度测量。
- 抽屉打开、搜索结果重绘和新增配方刷新时都会重新计算。
- 密度 class 每次测量前清除，避免由旧宽度或旧内容留下错误状态。
- 测量逻辑只操作当前行，不读取或写入分数、配方持久化等业务数据。

## 测试

真实浏览器测试覆盖：

- 关闭按钮位于标题栏右侧，点击后关闭抽屉；
- 按钮不再具有红色交通灯样式，仍有可访问名称；
- 桌面抽屉宽度为 480px，小屏不超过视口宽度；
- 普通公式不增加紧凑 class；
- 长公式进入紧凑或超紧凑 class，并且最终不换行；
- 缩放后的元素仍可拖拽和双击；
- 夜间模式按钮和长公式保持可读。

## 验收标准

1. 配方库不再显示左上角红色叉叉。
2. 右上角关闭按钮清晰、易点按并支持键盘操作。
3. 桌面抽屉更宽，小屏不溢出。
4. 普通公式尺寸不变，超长公式自动缩小并保持单行。
5. 配方交互和现有数据行为不变。
