# 移动端首发墙概览标题单行优化

## 目标

在不改变桌面端布局、统计文案或数据逻辑的前提下，让移动端“震撼首发”概览卡的箭头、标题和右侧三项统计完整显示在同一行。

## 范围

- 仅调整 `frontend/wall/wall.css` 中 `max-width: 780px` 的移动端样式。
- 保留“已加载”“全球已发现”“待发现”三个完整标签及其现有数据绑定。
- 不修改首发列表、排行榜、折叠交互或后端接口。

## 布局设计

- 标题区域禁止换行和收缩，确保“震撼首发”保持单行。
- 统计区域禁止换行，但允许占用剩余空间。
- 标题字号、字重与“悬赏清单”保持一致；统计标签和数字继续沿用同一套概览卡字号层级。
- 在移动端仅压缩卡片横向内边距、箭头宽度、数字边距、分隔符和项目间距，不通过单独缩小“震撼首发”字体来换取空间。
- 桌面端继续使用现有字号与间距。

## 验收标准

- 宽度不超过 780px 时，“震撼首发”四个字不得折行。
- “已加载”“全球已发现”“待发现”及其数值在标题右侧保持同一行。
- 内容不横向溢出概览卡。
- “悬赏清单”和“震撼首发”的标题字体保持一致，两张卡片的统计文字层级保持一致。
- 现有桌面端样式和交互保持不变。

## 测试

在现有首发墙 UI 测试中增加静态样式契约，验证移动端媒体查询包含：

- 标题的 `white-space: nowrap` 与禁止收缩规则。
- 统计区域的单行规则。
- 移动端专用的紧凑间距和横向内边距。
- 两张概览卡标题与统计信息的字体规则保持一致。
