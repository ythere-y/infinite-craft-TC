# Issue #16 手机端主游戏布局与触控适配设计

## 背景与目标

主游戏当前以桌面端固定顶栏和右侧元素栏为主。手机竖屏下，顶栏入口容易拥挤，固定元素栏会持续压缩画布，触控拖拽还可能与页面滚动、浏览器手势和双击复制冲突。

本次改动仅作用于常见手机竖屏，保持画布为核心操作区域，同时保证搜索、元素拖拽、合成、图鉴、等级、清空、首发榜和帮助入口可用。桌面端布局、文案与鼠标双击复制保持不变。

## 范围

### 包含

- 主游戏页面的手机竖屏响应式布局。
- 手机端两行顶栏及完整花名展示。
- 合成区和元素区的纵向排列。
- 合成区完整矩形及引导文字完整展示。
- 触控拖拽、滚动、软键盘和安全区适配。
- 手机端禁用双击或连续轻触复制。
- 相关前端自动测试和桌面端回归验证。
- 浅色主题与 URA 主题下的新组件样式。

### 不包含

- 后端接口、数据库或 Makers KV 变更。
- 社区广场、首发榜等独立页面的整体移动端重构。
- 新前端框架、路由系统或账号系统。
- 平板横屏或桌面端布局重设计。

## 布局与组件

### 桌面端

断点以上继续使用现有布局：单行完整顶栏、固定右侧元素栏和主画布。本次不改变桌面端的结构、尺寸、文案或交互。

### 手机端

- 页面采用纵向自然流布局并允许纵向滚动，根页面不产生非预期横向滚动。
- 顶栏改为两行。操作入口在可用宽度内换行排列，花名单独占据可用行宽，取消省略号与最大宽度限制，完整显示昵称文字。
- 合成区位于顶栏下方，显示为完整矩形，不被底部元素区覆盖或裁切。
- 合成区根据引导内容设置足够的最小高度；引导、9 步案例、署名和参考链接全部显示，文字可正常换行，不通过隐藏、截断或过度缩小字号来塞入一屏。
- 手机帮助文案将“右边的元素”调整为“下方的元素”，并隐藏桌面端双击复制说明；桌面端原文保持不变。
- 现有侧栏在手机端转为合成区下方的底部元素区，不使用抽屉、遮罩或悬浮覆盖。
- 底部元素区按搜索框、已发现数量、元素列表的顺序显示。搜索框占满可用宽度，数量文字完整显示，元素列表在受限高度内独立纵向滚动。
- 元素仍可从底部列表拖入上方合成区；触控拖拽时不触发页面滚动或浏览器手势。
- KPI、图鉴、昵称确认等已有面板在小屏幕下受视口宽高约束，并使用内部滚动，避免被软键盘或安全区遮挡。

新布局沿用现有按钮、圆角、边框、阴影和主题颜色。URA 模式为两行顶栏、矩形合成区和底部元素区提供对应暗色规则，不引入独立视觉体系。

## 状态与事件流

移动端布局主要由 CSS 媒体查询完成，不新增抽屉、遮罩或菜单状态，也不改变游戏数据。拖拽继续沿用现有状态，并在活动期间抑制冲突手势。媒体查询跨越手机断点时只改变布局，不影响画布、发现列表、昵称或得分状态。

拖拽流程继续使用现有 Pointer Events：

1. 元素收到主指针 `pointerdown` 后创建 ghost 并捕获指针。
2. 活动拖拽期间更新 ghost 和画布目标，不让页面滚动抢走手势。
3. `pointerup` 在画布内执行新增、移动或合成。
4. 如果拖拽取消或落在画布外，清理 ghost 和拖拽样式，底部元素区保持原位。
5. `pointercancel` 与普通释放走同一套幂等清理逻辑。

## 触控与双击规则

- 可拖拽元素使用合适的 `touch-action`，活动拖拽期间锁定冲突滚动。
- 底部元素列表和搜索框仍支持正常纵向滚动及文本输入。
- 双击复制仅接受鼠标指针。触摸、触控笔及触摸产生的合成 `dblclick` 不调用复制处理器。
- 手机帮助文案不展示双击复制提示；桌面帮助文案继续说明鼠标双击能力。
- 使用动态视口单位和安全区 inset，确保软键盘弹出后搜索框可见、列表可滚动，底部内容不被系统区域遮挡。

## 可访问性与错误处理

- 搜索框继续使用明确的 `aria-label`，顶部操作入口继续使用真实 `button` 或 `a` 元素及现有无障碍名称。
- 可点击入口保持足够的触控尺寸，并使用真实 `button` 或 `a` 元素。
- 拖拽清理必须幂等，重复事件不会遗留滚动锁或 ghost。
- API 错误继续使用现有合成反馈路径，本次不改变错误文案或重试策略。

## 测试与验收

### 自动测试

- 验证 CSS 在手机断点下将顶栏改为两行、完整显示花名，并将布局改为合成区在上、元素区在下。
- 验证合成区保持完整矩形，引导文字允许换行且没有裁切或隐藏规则。
- 验证 CSS 包含安全区、动态视口、防横向溢出和底部元素列表滚动规则。
- 验证移动端文案使用“下方的元素”且不显示双击复制提示，桌面端原文仍然存在。
- 验证 double-tap 处理拒绝非鼠标指针，同时保留鼠标 `dblclick`。
- 运行 `npm test`。
- 运行 `python3 -m pytest tests --ignore=tests/test_combine_feedback.py -q`。
- 运行 `npm run build`。

### 手动验收

- 在常见手机竖屏宽度（至少 320、375、390 和 430 CSS px）检查无横向滚动、顶栏溢出或界面遮挡。
- 验证顶栏为两行且花名完整显示，无省略号或裁切。
- 验证合成区是完整矩形，并完整显示引导、9 步案例、署名和参考链接。
- 验证底部元素区位于合成区之后，搜索元素、纵向滚动列表，并拖入画布完成一次合成。
- 连续轻触侧栏、图鉴和画布元素，确认不会复制。
- 用桌面鼠标验证拖拽、合成和双击复制无回归。
- 验证配方库、等级、清空画布、首发榜和帮助入口可用。
- 在浅色和 URA 主题下检查两行顶栏、矩形合成区、底部元素区、按钮和面板视觉一致。
- 聚焦搜索框并弹出软键盘，确认输入框和列表仍可操作。
- 在带安全区的设备模拟下确认顶栏和底部内容不被遮挡。
